# Pedin Run — instruções do projeto

Antes de alterar qualquer elemento visual, leia `docs/09-style-guide.md` e confira `docs/referencias/pedin-run-conceito.png`.

O style guide é obrigatório para HUD, menus, página externa, carregamento, personagens, cenários, efeitos e controles. Em divergências com documentos visuais anteriores, ele prevalece. Assets gerados e UI existente não são referência aprovada.

Não introduza visual de dashboard, glassmorphism, blur, cantos suaves, emojis como ícones finais ou fontes de sistema na UI final. Use a linguagem pixel art definida no guia, inclusive em HTML/CSS acessível.

Não trate build ou testes de lógica como aprovação estética. Registre validação visual pendente quando não puder verificar a interface em navegador. Atualize a documentação conforme cada etapa real da migração.
